# Roadmap

## Completed

- **2026-11-02 — keep-review-stats-remove-today**: Deleting a set (or cards, or merge sources) no longer shrinks the stats: its `ReviewHistory` and answered `SessionCard` rows, for every user who studied it, are rolled into the new `ReviewActivityArchive` table (per user, UTC day) in the same transaction, and the heatmap, lifetime review count (unverified study limit, streak-restore credit) add it back. Migration `20261102090000_add_review_activity_archive`. The "Today" adaptive coach is removed (`/today`, `/api/v1/today`, `/api/v1/user/study-goals`, its nav item, `todayPage` catalogs, learning queue/goals/insights services); the dashboard due alert and the study reminder now open `/study`. `UserStats.dailyGoalCards` is left in place, unused. Specs removed (`today-learning-page`, `daily-learning-queue`, `daily-study-goals`, `retention-insights`, `recommended-study-session`); updated (`dashboard-search-library`, `user-settings`, `pwa-service-worker`).
- **2026-11-01 — guide-chat-knowledge**: Guide FAQ grows from 6 to 21 entries (AI generation and its background run, AI limits, CSV/JSON import, split, merge, sharing/library/duplicate, Today, spaced repetition, Draw and Meteor Defense, session customisation, theme/language, offline study, email verification, passwords) plus `ai-generate` and `import-set` flows. The chat shows 3 suggested questions and a "…" toggle that expands the full list of 14 (all locales). Spec updated (`ai-assistant-chat-box`).
- **2026-11-01 — motapi-ai-provider**: Ollama and the Z.ai fallback are gone; AI set generation and the guide chat call MotAPI (OpenAI-compatible) through `@ai-sdk/openai`, with separate ordered model lists per use case (`MOTAPI_SET_MODELS` / `MOTAPI_CHAT_MODELS`, defaults in `src/config/motapi-env.ts`). `withModelSwitch` replaces the retry cascade: one call per model, any error, timeout, empty or unparsable output switches to the next, at most 3 calls, SDK retries off. AI set generation now runs in the background: the request lives in an app-wide job store, the modal can be closed ("Continue in background"), and a persistent toast announces the finished set with an "Open set" link (or the failure) on any app page. Specs updated (`ai-generate-set-api`, `ai-generate-modal-ui`, `ai-assistant-chat-box`).

- **2026-10-26 — email-verification-limits**: Email verification stays non-blocking, but unverified password accounts cannot publish sets (create/import/switch to `PUBLIC` → `403 EMAIL_NOT_VERIFIED`; already public sets stay public) and get 3 AI set generations per 24h (`429 AI_QUOTA_UNVERIFIED`; the slot is given back when generation fails). One rule (`isEmailConsideredVerified`: confirmed, or OAuth-only) drives `/api/v1/auth/me`, settings and the gates. Google sign-in now links to an existing email when Google verified it: an unverified password account is taken over (password and pending tokens dropped, sessions revoked, notice email with a set-password link); a verified one just gains Google; an unverified Google address returns to `/login` with a message. Settings: resend-confirmation box for unverified accounts, Google accounts show as verified with a set-password link; Public option disabled with a hint in set and import forms. Theme picker hydration mismatch fixed (`useIsClient`). Specs updated (`user-settings`, `google-oauth`).

- **2026-10-26 — merge-sets**: Merge two or more of your own sets into one new private set (the reverse of split), e.g. to test finished parts together. `POST /api/v1/sets/merge` (`mergeSets` in `set.service.ts`): cards copied in pick order, optional duplicate removal (same front + back, case-insensitive; on by default), shared language kept, sources untouched, fresh SM-2 progress for the copies, max 20 sets / 5000 cards. UI: My Sets "Merge sets" selection mode and set detail "Merge with…", both opening `MergeSetsDialog` with a suggested title (`Vocab (1, 3/5)` for split parts). No schema change. Spec updated (`flashcard-management`).

- **2026-10-26 — confirm-dialog**: Deleting a set and bulk-deleting cards use a shared in-app `ConfirmDialog` (title, description with set name and card count, pending state, inline error) instead of the browser `window.confirm`; `DialogDescription` added to the dialog primitives.

- **2026-10-26 — study-auto-advance**: Shared answer feedback for Learn, Write, Test and spaced review (`useAnswerAutoAdvance`: correct → chime + 1s, incorrect → 5s, Continue / Enter skips; Draw adds chime + Continue). Flashcard grading: → / swipe right / "Know it" (chime) and ← / swipe left / "Still learning" (card returns next round); back button and end-of-round banner removed, autoplay passes cards without grading, swipe fly-out cannot grade twice, Space/arrows ignored in text fields, IME Enter never submits. Settings gain a Study section with a chime toggle. Specs updated (`study-modes`, `user-settings`).

- **2026-10-25 — settings-page + mobile polish**: New `/settings` page (Appearance: registry-driven theme preview cards; Language: native-name list; Account; Change password via `POST /api/v1/user/password`, which revokes all sessions). Avatar menu reduced to Settings + Sign out on every width, sidebar gains a Settings link; shared `useChangeLocale` / `useSignOut` hooks. Mobile fixes: dialogs inset from screen edges and scroll within `100dvh`, select values truncate instead of widening dialogs, menus keep 8px collision padding, inputs use 16px text on phones (no iOS focus zoom), landing header fits 375px. Spec added (`user-settings`).

- **2026-10-24 — paper-ink-theme**: Fourth visual theme "Paper & Ink" in light (`paper`) and dark (`paper-dark`): editorial notebook look (cream paper with faint rules, navy ink outlines, sticky-yellow offset shadows, Be Vietnam Pro). Test-mode correct option also shows a check icon. Spec updated (`ui-design-system`).

Specs updated (`ui-design-system`, `ui-components`, `ai-assistant-chat-box`).
